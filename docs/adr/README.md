## What is an ADR?
An Architectural Decision Record (ADR) captures an important architectural or technical decision made for this project, along with its context, rationale, consequences, and alternatives considered.

This ensures that crucial design choices, technical trade-offs, and curriculum workflows are **never lost in ephemeral chat conversations** and can be reliably referenced by any agent or engineer throughout the project life cycle.
